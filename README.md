# Vijay Ram career website

Personal career site for Vijay Ramasubramanian (Ram): operational excellence, Lean Six Sigma, and the data and AI layer.

- Edit the page in `src/content.html`, then run `./build.sh` to regenerate `index.html`.
- `ml-agent/` is a private, in-browser machine learning and DOE agent. See `ml-agent/README.md`, `ml-agent/DEMO.md` (demo script) and `ml-agent/DEPLOY.md` (intranet hosting).
- Host free on GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
